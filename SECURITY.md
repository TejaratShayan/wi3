# Security Policy

Because **wi3** includes installation scripts that use `sudo`, manage `sudo -A` askpass prompts (`rofi-sudo`), and wrap VPN clients (`openfortivpn`, `vless-tun`), we take security seriously.

## Reporting a Vulnerability

If you discover a security vulnerability (such as command injection, privilege escalation, or credential leakage):

1. **Do not** open a public GitHub issue.
2. Report it privately using GitHub's **Security Advisories** feature on `TejaratShayan/wi3` (or contact the repository maintainers directly).
3. Include a clear description of the issue, affected script(s), and steps to reproduce.

We will acknowledge your report and work on a fix as quickly as possible.
